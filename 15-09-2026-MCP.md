# Day 01 — Learning Model Context Protocol (MCP)

Today I learned about **Model Context Protocol (MCP)** and how it allows AI applications to connect with external tools, data, and services.

## What I Learned

I learned that an LLM mainly works with the knowledge available from its training. By itself, it cannot directly access external databases, files, APIs, or applications.

**MCP acts as a bridge between an AI application and external tools or data.** It provides a standardized way for an AI application to discover and use these external capabilities.

## MCP Architecture

I learned about the main components of MCP:

* **MCP Host** — The AI application where the LLM runs.
* **MCP Client** — Handles communication between the LLM and MCP servers.
* **MCP Server** — Provides external tools, data, or capabilities to the AI application.
* **Transport Layer** — Handles communication between the client and server, including stdio and SSE.

## How MCP Works

The basic flow is:

**User → LLM → MCP Client → MCP Server → External Tool/Data → MCP Server → LLM → User**

For example, an AI assistant could retrieve information from a database using one tool and then use another tool to perform an action such as sending an email.

This helped me understand how AI applications can move beyond simply generating text and start **interacting with external systems and performing tasks.**

## MCP vs RAG

One important concept I learned is the difference between MCP and RAG.

* **RAG** retrieves relevant information from external sources and provides it to the LLM to improve its response.
* **MCP** provides a standardized way for AI applications to interact with external tools, services, and data.

In simple terms:

**RAG → Give the AI the right information.**

**MCP → Give the AI a way to use external capabilities.**

## Security

I also learned that connecting AI applications to external tools introduces security considerations.

Some important areas are:

* User consent and control
* Data privacy
* Safe tool execution
* Secure output handling
* Supply-chain security
* Monitoring and auditing

This showed me that building AI agents is not only about giving them more capabilities, but also about making sure their actions are **safe and controlled.**

## Key Takeaway

My main takeaway from today's learning is that **MCP provides a standardized way for AI applications to connect with external tools and data.**

It is an important concept for building AI agents that can not only understand and generate information but also **retrieve data, use tools, and interact with external systems.**
